# NEWS SQUARE

タイムズスクエアの電光掲示板のように、ニュースを LED 風の文字で流すページです。
好きな RSS フィードを設定すると、自分専用の電光掲示板として 5 分ごとに自動更新されます。

- 左右 2 面のビルボード（地域ごと）と、2 段の電光テロップ
- 新着は「NEW」付きでビルボードに即表示
- 英語の見出しは日本語に自動翻訳（原文も併記）
- サーバー不要。GitHub だけで無料で動きます

## 使い方（5 分）

1. このページ右上の **Use this template → Create a new repository** で自分のリポジトリを作る（Public）
2. `config.json` を開いて、`feeds` に好きな RSS の URL を書く
3. **Settings → Pages** で Branch を `main` / `(root)` にして Save
4. **Actions → ニュース自動取得 → Run workflow** を押す（以後は 5 分ごとに自動で動きます）
5. 数分後、`https://<あなたのユーザー名>.github.io/<リポジトリ名>/` を開く

## config.json

| 項目 | 内容 |
|---|---|
| `title` | ページのタイトル |
| `regions.jp` / `regions.wd` | 左右のビルボードの名前（`label` は画面上、`short` はボタン） |
| `feeds` | `region`（`jp` か `wd`）、`category`（分類名）、`source`（出典名）、`url`（RSS） |
| `translate` | 英語見出しを日本語に訳すなら `true` |
| `perRegion` | 地域ごとに残す件数 |

見本では、デジタル庁・総務省・NASA の新着情報を使っています。

## フィードを選ぶときの注意

ニュースサイトの RSS には、個人利用に限る・商用利用不可などの条件が付いていることがあります。
見出しを継続的に配信すること自体が問題になった裁判例もあるため、公開するページで使うフィードは、各サイトの利用規約を確認してから設定してください。
このテンプレートは見出しとリンクだけを表示し、本文は表示しません。

## 検索エンジンについて

`index.html` の `<meta name="robots" content="noindex,...">` により、検索結果には載らない設定になっています。
載せたい場合はその行を削除してください。

## 翻訳について

無料の翻訳サービス（Google 翻訳の公開エンドポイント → 失敗時は MyMemory）を使っています。
無料枠を超えた場合は英語のまま表示し、次回の更新で再度訳します。商用で使う場合は有料の翻訳 API に置き換えてください。
